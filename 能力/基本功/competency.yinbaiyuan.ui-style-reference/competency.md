# 界面风格参考

用于收录值得借鉴的界面、组件和动效案例，也用于在设计任务中按场景查找参考。输出是可回到原页面的参考条目，或带取舍依据的短名单，供后续视觉设计和交互原型使用。

## 查找与选用

1. 先说清这次要解决什么，例如高密度看板的阅读顺序、确认按钮的操作反馈，或品牌首页的首屏表现。已有产品先对齐现有视觉语言和组件规则。已有规范足以解决问题时，直接沿用。
2. 读[风格参考库](references/style-library.md)，先按场景筛，再按参考粒度选。页面结构看同类页面，交互反馈看能观察输入和状态变化的组件示例。通常选 1–3 条，每条写清适用页面或控件、可借鉴的具体做法和迁移条件。
3. 把「柔和」「有科技感」转成可以画进稿子或在原型里检查的决定，例如「核心数字放在卡片第一视觉层，单位和同期对比降一级」或「聆听时光环响应音量，同时用文字显示状态」。遇到死链或展示不全，保留已知线索和核验范围，优先换同场景的已确认入口。
4. 浏览公开示例即可形成设计参考。需要直接复用代码、模板或素材时，单独核对对应资产的授权、访问条件和现有技术栈。交付前确认每条推荐都能回答「为什么适合这次任务」「具体借鉴什么」。

## 收录与更新

用户要求收录时，在参考库里按同一字段追加。以产品或具体案例为单位查重，同一来源优先更新原条目，保留仍有用的旧入口和用户观察。记录名称、官方入口或用户提供的来源、风格观察、适合场景、可借鉴点，以及已知的访问条件和核对日期。审美判断与官网可确认的事实分别记录。没有可靠来源时标「待核实」，保留原线索。完成后读回改动，确认入口和场景都可用于下次查找。
