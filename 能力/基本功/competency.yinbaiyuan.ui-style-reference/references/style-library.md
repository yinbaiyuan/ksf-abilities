# 界面风格参考库

首批 6 条来自超哥提供的清单。风格和适用场景是设计观察与建议。官网入口及下文列出的公开内容核对于 2026-11-05。

| 来源 | 风格观察 | 适合场景 | 可以借鉴 |
| --- | --- | --- | --- |
| [BoardUI](https://www.boardui.com/) | 偏苹果系，干净克制，柔和配色、圆润卡片、清晰的信息层级。 | 管理后台、数据看板、高密度指标页。 | 观察指标卡片、图表和列表的分组与间距，让重点数字优先被看到。 |
| [Bencho](https://bencho.dev/) | 微交互细腻，用磁吸、滑动和拖拽表现控件的状态变化。 | 打磨按钮、菜单、滑块和卡片等控件。 | 看[磁吸选择](https://bencho.dev/blocks/magnet-select)、[滑动确认](https://bencho.dev/blocks/slide-confirm)和[卡片拖拽切换](https://bencho.dev/blocks/card-swap)，观察触发、进行中和完成反馈。 |
| [HeroUI Pro](https://heroui.pro/) | 成熟利落的产品感，字体、间距、圆角和配色统一。 | 产品后台、个人工具等高频操作界面。 | 参考表格、筛选器、表单和弹窗的密度与层级，保持同类操作的位置、尺寸和反馈一致。 |
| [beUI Pro](https://pro.beui.dev/) | 渐变光影、插画和动效更有表现力，首屏与页面版式多样。 | 有品牌辨识度的产品、首屏、功能展示及整站模板。 | 在[公开预览](https://pro.beui.dev/explore)对比首屏构图和内容节奏，挑一个焦点承载视觉表现。 |
| [Libraries.dev](https://libraries.dev/) | 未来感和 AI 科技感明显，动态光球、声音光环与液态金属有代表性。 | AI 正在思考、聆听或生成时的界面反馈。 | 对照思考光球、语音光环和生成效果，分别设计状态反馈，并配合文字标明实际状态。 |
| [Watermelon UI](https://ui.watermelon.sh/) | 从简洁工具界面到有表现力的展示页面都有，适合横向比较布局。 | 视觉方向未定、需要快速比较页面结构时。 | 从同类组件、区块、看板或模板中挑两种布局，用同一份内容比较导航和阅读顺序。 |

## 入口和访问条件

- BoardUI 官网提供公开内容，并列有免费入口和 Pro 方案。 [BoardUI 官网](https://www.boardui.com/)
- Bencho 的公开站点是 `bencho.dev`。原清单写的是 `bencho.com`，本次未能确认该地址。 [Bencho 组件目录](https://bencho.dev/)

- beUI Pro 的公开站点是 `pro.beui.dev`，有公开预览，Pro 素材按方案提供。原清单写的是 `beui.pro`，本次未能确认该地址。 [beUI Pro 官网](https://pro.beui.dev/)
- Libraries.dev 有公开效果示例。直接复用时按具体库或资产核对许可及 Pro 功能范围。 [Libraries.dev 官网](https://libraries.dev/)
- Watermelon UI 的公开站点是 `ui.watermelon.sh`。原清单写的是 `watermelon-ui.com`，本次未能确认该地址。 [Watermelon UI 官网](https://ui.watermelon.sh/)
