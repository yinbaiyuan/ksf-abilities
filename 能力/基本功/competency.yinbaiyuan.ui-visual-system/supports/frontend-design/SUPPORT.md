# 视觉方向与表达 · 可选支持

## 用途与触发

当产品题材已清楚、需要新的展示页面或视觉方向时，读取原始定义；现有界面小修可以不用。

## 输入输出

最小简报、品牌约束、真实/标注示例内容、已有规范 → 精简的色彩/字体/构图方案与可见界面。

## 调用与方法

按需读取原始定义，完成题材相关的视觉判断；保留基本功要求的同内容概念和推荐，再用真实画面检查。来源中的记忆写入建议不产生跨任务保存授权。

## 依赖

读取 upstream/SKILL.md 与 LICENSE.txt，无专用运行时。需要代码/浏览器时使用当前工程环境。

## 限制与本次证据

本次咖啡页产生了蓝色粗体与斜切画面的替代方向；并未证明它比基线更受用户喜欢。风格禁令作为审美提示，不能覆盖已确认品牌。没有明确 subject 只问会改变方向的缺口，不制造“客户已拒绝过”的事实。

## 不可用时

依赖不可用时按视觉基本功继续，交付当前能查看的概念及限制。

## 来源与维护

原始包保存在 upstream/，不改写原件；本文件是包外适配。来源、精确快照/本机版本、文件哈希见 SOURCE.json。升级先检查差异与依赖，再重跑受影响场景，不自动追踪main。本支持没有 KSF 对象 ID，不写入 references，也不创建全局/根 .agents/skills 入口；由基本功根据实际缺口按需读取。
